# Video Transcoder

A web-based video transcoding application built with React that allows users to convert videos between different formats.

## Features

-   Browser-based video transcoding
-   Support for multiple video formats
-   Modern and responsive user interface
-   Client-side processing

## Tech Stack

-   React.js (80%)
-   HTML (13%)
-   CSS (7%)

## Getting Started

1. Clone the repository

```bash
git clone https://github.com/Aninda001/video-transcoder.git
cd video-transcoder
```

2. Install dependencies

```bash
npm install
```

3. Start the development server

```bash
npm start
```

The application will be available at http://localhost:3000

## Building for Production

To create a production build:

```bash
npm run build
```
